# Landing display font

**Fraunces** (weights 600 and 700, Latin subset) is self-hosted for landing headings.

- License: SIL Open Font License 1.1 (see `OFL.txt`)
- Upstream: https://github.com/undercasetype/Fraunces
- Files: `fraunces-latin-600-normal.woff2`, `fraunces-latin-700-normal.woff2` (Fontsource latin builds, v5.2.5)
- Use: heading / kicker / display type on the public landing page only. The signed-in app stays on the system UI stack.
